# docs/distribution

Everything needed to take Toolkitty from "published" to "known", in the order it is used. Written
2026-11-09. Nothing here ships inside the plugin.

| File | What it is | When |
|---|---|---|
| `STATUS.md` | What is live, which gates are open, requests to the builder session, log | always current |
| `WAVE-A-INVITE.md` | Final beta invitation, English and Hebrew, long and short, follow-ups, exit criteria | Week 1 |
| `WAVE-A-TESTERS.csv` | Tester tracking sheet (one row per tester) | Week 1–2 |
| `WAVE-A-FEEDBACK-QUESTIONS.md` | The three questions in the invite, the follow-up questions, how to read answers | Week 1–2 |
| `CHANNEL-MAP.md` | Every channel considered, its rule as checked, the angle, the gate, and what was skipped | before any post |
| `copy/SHOW-HN.md` | Title options, body with real numbers, prepared answers | HN day |
| `copy/REDDIT.md` | r/ClaudeAI, r/ClaudeCode, r/commandline, r/SideProject, optional Hebrew | launch week |
| `copy/X-THREAD.md` | Six tweets with asset per tweet | HN day |
| `copy/LINKEDIN.md` | Post plus first comment with links | HN day + 1 |
| `copy/PRODUCT-HUNT.md` | Tagline, description, topics, maker comment, gallery order | Week 4 |
| `copy/DISCORD-AND-LISTS.md` | Discord showcase message, awesome-list submissions, Console.dev pitch, dev.to plan | Weeks 2–3 |
| `BRAND-KIT.md` | Name, lines, exact claim wording, logo do/don't, colours, tone with examples | always |
| `LAUNCH-CALENDAR.md` | 30 days from 2026-11-10 with gates G0–G3 | always |
| `METRICS.md`, `metrics/check.ps1`, `metrics/log.csv` | What to measure, the Monday routine, the script, the log | weekly |

Rules that bind every file: Avraham sees the exact text and target and says yes before anything is
posted; he posts himself. No paid promotion, no upvote requests, each community's own rules first. No
fabricated numbers; demo data is labelled DEMO. Claims only in the wording of `BRAND-KIT.md`.
